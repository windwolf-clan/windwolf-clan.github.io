빌드 방법

Visual Studio

  1. 새 프로젝트 → Windows 데스크톱 애플리케이션 또는 빈 프로젝트
  2. 생성된 소스를 지우고 이 페이지의 main.cpp 를 추가
  3. 빈 프로젝트라면 속성 → 링커 → 시스템 → 하위 시스템을 창(/SUBSYSTEM:WINDOWS) 으로
  4. Ctrl+F5 로 실행

명령줄 (x64 Native Tools Command Prompt)

cl /EHsc /std:c++20 /utf-8 /DUNICODE /D_UNICODE main.cpp /link /SUBSYSTEM:WINDOWS user32.lib gdi32.lib
