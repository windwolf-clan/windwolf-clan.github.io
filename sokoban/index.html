Win32로 소코반 만들기

엔진 없이 Win32 API 만으로 소코반 게임을 만드는 시리즈의 편별 전체 코드입니다. 편마다 그대로 빌드해 실행할 수 있습니다.

편 목록

  • 1편빈 창 띄우기

    엔진 없이 Win32 API만으로 소코반 게임을 만드는 시리즈의 첫 편입니다. WinMain부터 윈도우 클래스 등록, 창 생성, 메시지 루프, WndProc까지 빈 창 하나를 띄우는 뼈대를 만듭니다. 메시지 루프가 없을 때와 PostQuitMessage가 없을 때 실제로 어떻게 되는지도 실행해서 확인합니다.

  • 2편키보드 입력 받기

    Win32 API로 소코반을 만드는 시리즈 2편입니다. WM_KEYDOWN 메시지로 방향키 입력을 받아 좌표를 움직이고, 제목 표시줄에 표시해 확인합니다. 가상 키 코드와 wParam, ESC로 창을 닫는 방법까지 다룹니다.

  • 3편GDI 기초

    Win32 API로 소코반을 만드는 시리즈 3편입니다. WM_PAINT와 BeginPaint/EndPaint로 그리는 자리를 잡고, 브러시와 펜을 만들고 쓰고 지우는 GDI의 기본을 다룹니다. 격자를 깔고 방향키로 움직이는 원을 그려서, 값 변경 → InvalidateRect → WM_PAINT 흐름을 완성합니다.

  • 4편맵 데이터와 그리기

    Win32 API로 소코반을 만드는 시리즈 4편입니다. 맵을 문자열로 정의하고, 변하지 않는 지형과 움직이는 상자를 따로 담는 설계를 잡습니다. 벽·바닥·목표 지점·상자를 GDI로 그리고, AdjustWindowRect로 창 크기를 맵에 맞춥니다.
